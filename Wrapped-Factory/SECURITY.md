# Güvenlik Bildirimi

Bir güvenlik sorunu bildirecekseniz, istismar ayrıntılarını herkese açık issue olarak yayımlamak yerine depo sahibine özel bir kanaldan iletin.

- Gerçek GitHub erişim token'larını kaynak koda, commit'lere, issue'lara veya ekran görüntülerine eklemeyin.
- Bir token yanlışlıkla paylaşılırsa GitHub üzerinden derhal iptal edin ve gerekiyorsa yenisini oluşturun.
- Bu statik uygulamada kullanıcı tarafından yüklenen dosyalar tarayıcıda işlenmek üzere tasarlanmıştır. Yayın öncesi ağ isteklerini ve dosya işleme akışlarını kullandığınız tarayıcıda doğrulayın.
